# Labels de triage

As skills importadas falam em termos de cinco papéis canônicos de triage. Este arquivo mapeia esses papéis para os labels reais usados no Forgejo deste projeto (mesmo mecanismo de labels documentado em `workflow-issues`, seção "Passo 2 — Labels").

| Label em mattpocock/skills | Label no nosso Forgejo | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Precisa ser avaliada |
| `needs-info` | `needs-info` | Esperando mais informação de quem reportou |
| `ready-for-agent` | `ready-for-agent` | Totalmente especificada, pronta para um agente rodar sozinho |
| `ready-for-human` | `ready-for-human` | Exige implementação humana |
| `wontfix` | `wontfix` | Não será feita |

Quando uma skill mencionar um papel (ex.: "aplique o label de pronto-para-agente"), use a string correspondente da coluna da direita.

Edite a coluna da direita para bater com o vocabulário real que o projeto decidir usar — o padrão acima assume que os nomes originais servem sem alteração.
